# FUTURE_DS_02
Customer retention and churn analysis 
As part of this task I have analyzed retention trends and churn rates and presented insights for business advice

Data cleaning steps💻:• Removed unnecessary colums(row numbers, surname) •Renamed coulums for better understanding •converted data types •Transformed churn Values (0>No,1>yes)
KEY METRICS📊:•Total customers •Churn rate •Retention rate
DASHBOARD FEATURES📊:•KPI Card(Total customers,Churn rate, retention rate) •Churn by age group •Churn by tenure(the number of years a person has been a customer) •Churn by active member status •churn by number of products
INSIGHTS🔎:Non-credit card holders account for a larger portion of churn rate • Germany and Spain have better customer retention •France has the highest churn which accounts for 20% of customers
RECOMMENDATIONS✏️📍:•Employ data-driven churn strategies,such as Machine Learning models to forecast which customers are likely to leave •Establish clear benchmarks for customer and revenue churn rate based on industry standards to guide investigating •Shift from risk-based retention to engagement-based retention to prevent churn among non-credit cardcholders-typically customers with only checking or savings accounts
